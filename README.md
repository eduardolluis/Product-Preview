# Product Preview Card

A responsive product preview component built with **HTML** and **CSS**. The project recreates a product card layout with product imagery, pricing, descriptive copy, and an add-to-cart call to action.

## Highlights

- Responsive card layout
- Product image and pricing presentation
- Custom typography with Google Fonts
- Clean HTML and CSS implementation
- Frontend Mentor practice project

## Tech Stack

- HTML5
- CSS3

## Run Locally

No build step is required. Clone the repository and open `index.html` in a browser.

```bash
git clone https://github.com/eduardolluis/Product-Preview.git
cd Product-Preview
```
